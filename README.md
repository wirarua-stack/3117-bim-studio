# 3117 BIM Studio

Free and open-source BIM authoring workbench for FreeCAD, developed for 3117 BIM Management.

## Development status

The current workbench is a v0.5.0 Types and Quantities development candidate. It includes Project, Levels, Grid, Wall, Door, Slab, Column, Beam, Window, drawings, types, quantities, schedules, and IFC exchange within the documented scope.

Windows acceptance of a pinned FreeCAD 1.1.4 history fix is the active milestone. A verified Windows installer is not yet available.

## Active acceptance branch

- [Windows build and acceptance kit](https://github.com/wirarua-stack/3117-bim-studio/tree/acceptance/windows-history-fix)
- [GitHub Actions runs](https://github.com/wirarua-stack/3117-bim-studio/actions)

The acceptance branch contains the frozen workbench source, exact regression inputs, build scripts, test runners, and evidence requirements. Linux validation and offline checks must not be interpreted as Windows acceptance.

No upstream submission or merge is included in this milestone.
